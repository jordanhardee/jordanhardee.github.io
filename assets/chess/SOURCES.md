# Chess piece artwork

The twelve SVG piece images in this directory are the **cburnett** chess set by
Colin M. L. Burnett, redistributed from
[Lichess (lila)](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett).

License: **GNU GPL version 2 or later**, as listed in
[Lichess's COPYING.md](https://github.com/lichess-org/lila/blob/master/COPYING.md).
The full GPL version 2 license text is already included in this repository at
`assets/doom/COPYING`. No modifications were made to the original SVGs.

The site's chess engine is the separately credited, self-hosted chess.js
library. The board and game UI are original website code.
